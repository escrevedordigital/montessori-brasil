# Educar as crianças para uma nova era

Site do projeto de pesquisa de pós-doutorado *"Educar as crianças para uma nova era: circulação e apropriação do pensamento montessoriano no Brasil em confluência com o movimento internacional da educação nova"*.

- **Proponente:** Dr. Vinicius de Moraes Monção (UFF)
- **Supervisor:** Dr. José Gonçalves Gondra (UERJ)

## Como publicar

1. Suba todos os arquivos deste pacote para um repositório público no GitHub.
2. Em **Settings > Pages**, selecione a branch `main` e a pasta `/ (root)`.
3. O site ficará disponível em `https://seuusuario.github.io/nome-do-repositorio`.

## Como editar conteúdo

Todos os textos estão em arquivos `.md` (Markdown), editáveis diretamente pela interface do GitHub (ícone de lápis em cada arquivo), sem necessidade de instalar nada.

- `index.md` — página inicial
- `about.md` — sobre o projeto
- `biografia-montessori.md` — biografia de Maria Montessori
- `circulacao-brasil.md` — casos de circulação no Brasil
- `fontes.md` — banco de fontes (ciência aberta)
- `bibliografia.md` — referências
- `redes.md` — análise social das redes
- `publicacoes.md` — publicações e resultados
- `contato.md` — contato
